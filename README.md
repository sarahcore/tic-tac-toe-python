# ❌⭕ Tic Tac Toe

A simple two-player Tic Tac Toe game built in Python and played directly in the terminal.

This project was created to practice programming logic and fundamental Python concepts through a classic game.

## 🎮 How It Works

Two players enter their names and take turns playing as **X** and **O**.

The board positions are numbered from 1 to 9, making it easy for each player to choose where to place their symbol.

The game:

- Alternates turns between Player X and Player O
- Prevents players from choosing an occupied position
- Validates whether the input is a number from 1 to 9
- Detects all possible winning combinations
- Detects a draw when the board is full
- Displays the final board and the result

## 🛠️ Technologies

- Python 3
- Python built-in functions

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run the command: `python tic_tac_toe.py`
5. Enter the players' names and follow the position guide displayed in the terminal.
